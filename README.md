# Women Safety Analytics

## Project Description
Women Safety Analytics is a web application that predicts women's safety based on input data and helps create awareness using machine learning.

## Features
- Safety prediction
- User-friendly interface
- Machine learning model
- Fast and simple analysis

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Machine Learning
- GitHub

## How to Run
1. Install the required libraries.
2. Run app.py.
3. Open the application in your browser.
